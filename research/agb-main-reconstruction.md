# Sapphire `AgbMain` reconstruction

The Japanese release `axp-j-rev0-retail` is the origin reference. All 12 cataloged releases (Japanese, English, German, French, Italian, Spanish) were followed from the GBA ARM entry branch through the literal-backed ARM-to-Thumb bootstrap transition into `AgbMain`. The observed builds form 2 explicit structural variant(s); each release is checked against its variant's direct-call name sequence, call offsets, target equivalence and edge-kind shape, plus one backward main-loop branch, and no return. Per-release maps preserve addresses, code hashes, calls, entry-chain evidence, and raw-free control-flow summaries. No ROM instruction bytes are published. Symbol names remain based on `pret/pokeruby` at `5784633ce4ef7ade1a7f2d2d0c288e3d5e6cdd7f`, `src/main.c`.
