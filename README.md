# PocketMonsters-Sapphire-Decompilation

Clean-baseline decompilation and reverse-engineering project.

Earlier commits remain historical reference; old layouts, migration trees, structure-version namespaces, and unfinished working trees are not restored automatically.

## Principles
- Verify exact target identity and provenance before version-specific claims.
- Separate observation, hypothesis, and unknowns.
- Prefer editable source, reproducible tools, manifests, hashes, and verification.
- Deduplicate only after byte/hash confirmation.
- Keep reviewable derived assets when useful and traceable.
- Never commit retail/rebuilt ROMs, decrypted full-game images, keys, or disguised complete game images.
- Keep one current live structure; Git history is the history layer.
- Historical work is reintroduced only after review against current standards.
