# Project Documentation

This directory is the documentation hub for the decompilation project.

Planned documentation areas:

- `formats/` — file and data-structure formats
- `executables/` — executable layout, symbols, functions, and subsystems
- `scripts/` — script engines, opcodes, events, and behavior
- `assets/` — graphics, audio, maps, text, and resource formats
- `versions/` — regional, language, revision, and update differences
- `verification/` — hashes, manifests, tests, and reproducibility notes

Documentation should cite the exact game version or revision whenever findings are version-specific.
